# Jcode by UlixDevLab

A maintained Jcode customization and distribution project, based on
[1jehuang/jcode](https://github.com/1jehuang/jcode).

## Status

Repository preparation is in progress. No installers or new runtime releases
are published here yet. Do not treat this placeholder as an install guide.

## Planned public distribution: Lite Free

- User-owned provider subscriptions and a user-selected main model.
- Task-appropriate worker models and curated everyday workflows.
- Selected MCP integrations, skills, roles, hooks and permission controls.
- Upstream Jcode improvements, including its Jev integration.
- Complete installers and verified updates for supported platforms.

The public edition will not contain private router credentials, download PINs,
or personal session data. Model/provider access is separate from the free
workflow bundle and may require the user's own subscription or API account.
