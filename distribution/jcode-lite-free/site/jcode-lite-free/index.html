Не новий Jcode. Продумана збірка.

Ми не переписували сильний open-source інструмент. Ми взяли його ефективний Rust runtime, додали перевірені Sage-дослідження, 19 бізнес-ролей, memory та Knowledge OS — і залишили зрозумілий старт.

Основа: jcode by 1jehuang, open source під MIT. Наша частина: curated Lite package з Stables routing, Sage-informed runtime, 19 expert skills + 6 workflow-обгорток, Memory з embeddings, Mage, Knowledge OS, PDF-переглядач, headless Playwright. Те саме, що люблять developers, але простіше запускається щодня.

Що ми взяли з Sage

Sage — це наш дослідницький проєкт, який вивчає, як саме агенти витрачають свій контекст. Ми виміряли, що реально допомагає, і перенесли принципи у поведінку runtime.

≈5×

Менше постійних інструкцій

У нашому аудиті Sage завантажував близько 9,550 tokens правил постійно, а вибраний Jcode overlay — близько 1,869. Тому ми не переносили Sage wholesale: контекст має йти на вашу задачу, а не на церемонію.

18 / 20

Менше повторної роботи

У 18 із 20 довгих Sage sessions знайшли дублювання context work. Runtime у цій збірці робить redundant re-reads видимими, обмежує worker execution і стискає completion wakeups.

EVIDENCE

Перевіряти ефект, не статус

«Tool завершився успішно» не означає, що бажаний результат зʼявився. Принцип — перевіряти реальний output, public interface або файл, який мав змінитися.

REVERSIBLE

Зміни мають мати шлях назад

Оновлення versioned, config користувача зберігається, є rollback. Складна паралельна робота має бюджети замість безмежного fan-out.

Навіщо Memory звичайній людині

Памʼять проєкту без ручної роботи

Memory embeddings перетворюють ваші нотатки, рішення та контекст на числа, які agent може швидко знаходити. Ви не пишете пошукові запити — agent сам згадує потрібне. Memory sidecar — це окремий маленький helper, який стежить за важливими фактами, коли ви працюєте.

Простими словами: agent памʼятає, що вирішили минулого тижня, без ручного копіювання в нотатки.

Чесно про embeddings: при першому використанні memory local embeddings можуть прозоро завантажити невелику модель у вашій системі. Це одноразова операція — після неї memory працює локально і без мережі. Ніяких додаткових кроків не потрібно.

Робочий процес розробника

Lite включає наш повний dev-workflow, який ми самі використовуємо кожен день. Це не вимагає знати Rust чи Git — але якщо знаєте, agent підключиться на цьому рівні.

01 · TDD

Спочатку тести

Agent пише тест, який описує очікувану поведінку. Потім код, який цей тест проходить. Це значно зменшує «майже працює».

02 · VERIFY

Перевірка, не віра

Кожна зміна має конкретний спосіб перевірки: build, тест, реальний output. Agent не каже «готово», поки ви не побачили результат.

03 · REVERT

Шлях назад завжди

Кожна дія записується у git track. Складна зміна блокується, якщо немає способу її відкотити. Це фіксує багато помилок до того, як вони сталися.

04 · DECIDE

Чіткі точки рішень

Agent сам зупиняється, коли треба ваш вибір між варіантами. Не «приймає рішення за вас», а просить короткий input.

05 · DELEGATE

Розділяє складну роботу

Swarm-механіка може розділити велику задачу між workers із обмеженими runtime budgets і компактними звітами. Головний agent не тоне у деталях.

06 · COMMIT

Часті коміти — це норма

Agent комітить часто й малими порціями зрозумілими повідомленнями. Так легше зрозуміти, що змінилося, і швидко відкотити.

Дослідження з розвідкою

Lite вміє запускати scouts — маленькі спеціалізовані агенти, які швидко збирають інформацію перед тим, як головний agent вирішує. Кожен scout має свою сферу і повертає короткий, цитований звіт.

Чесні trade-offs

Lite дає більше одразу, але install важчий, ніж Lite Free. Це перевага не для кожного.

Коли обрати Lite

  • Хочете Stables bundled без власного provider.
  • Потрібні 19 бізнес-ролей та 6 workflow-обгорток.
  • Memory з embeddings і sidecar мають працювати одразу.
  • Mage, Knowledge OS, headless Playwright і PDF із коробки.

Коли краще Lite Free або Original

  • Хочете свого provider — оберіть Lite Free.
  • Потрібен Linux або full-feature build — оберіть Original Jcode.
  • Не хочете extra install size — Lite Free помітно легший.

Чесні обмеження

Це речі, які треба знати перед install. Ми не приховуємо, що Lite — це більше, ніж Lite Free.

  • Розмір інсталяції більший. У Lite bundled Stables routing, 19 skills, memory embeddings, Mage, Knowledge OS, PDF, Playwright. Завантажений архів помітно більший за Lite Free.
  • Node.js 20 або новіший потрібен для Mage і Knowledge OS.
  • Системний браузер потрібен. Headless Playwright використовує ваш встановлений Chrome або Edge в ізольованому режимі. Lite не постачає власний браузер — потрібен стабільний локальний браузер.
  • Опціональні MCP service keys. Reddit bundled — anonymous-first: працює без setup для subreddit browsing через public RSS. Reddit credentials (free) — це додатковий unlock для search, comments, user analysis і вищих лімітів. Notion, OmniSearch, Lerim memory потребують власних API ключів для повної функціональності.
  • Stables bundled = вищий поріг прозорості. Якщо ви не хочете, щоб хтось платив за ваш AI — оберіть Lite Free.

Stables routing у Lite

Lite використовує наш Stables routing. Головний brain — MiniMax M3, швидкі механічні задачі йдуть на MiniMax M2.7 Highspeed. Це налаштування за замовчуванням, а не обмеження: ви можете підключити власний provider і обрати будь-яку модель.

Маршрутизація моделей
mainMiniMax M3 minimax/M3 через Stables (головний brain усіх задач)
scoutMiniMax M3 minimax/M3 через Stables (пошук у коді, читання файлів, research)
speedMiniMax M2.7 Highspeed minimax/M2.7-highspeed через Stables (швидкі механічні задачі)
volumeMiniMax M3 minimax/M3 через Stables (масштабні routine операції)

Все це працює «з коробки» — користувач не бачить складності маршрутизації, але отримує правильну модель для правильної задачі.

Чесно про Lite Free

Lite Free — це Lite без Stables. Той самий runtime, ті самі skills, та сама Mage і Knowledge OS. Різниця лише в одному: немає bundled AI, тож ви підключаєте власного провайдера.

  • Без bundled AI. Після install ви пройдете provider onboarding — оберете свій акаунт, введете ключ або OAuth.
  • Provider setup потрібен перед першою задачею. Lite Free не запустить жодну команду, поки provider не налаштований.
  • Без обмежень на provider. Lite Free підтримує тих самих провайдерів, що й Original Jcode — вибір за вами.

Not a new Jcode. A considered distribution.

We did not rewrite a strong open-source tool. We kept its efficient Rust runtime, added verified Sage research, 19 business roles, and automatic memory — and made the starting path clearer.

Foundation: jcode by 1jehuang, open source under MIT. Our layer: curated Lite package with Stables routing, Sage-informed runtime, 19 expert skills + 6 workflow wrappers, Memory with embeddings, Mage, Knowledge OS, PDF reader, headless Playwright.

What we kept from Sage

Sage is our research project that studies how agents spend their context. We measured what helps and moved the principles into runtime behavior.

≈5×

Less permanent instruction overhead

Our audit measured about 9,550 always-loaded tokens for Sage rules versus about 1,869 for the selected Jcode overlay. We did not port Sage wholesale: context should be spent on your task, not ceremony.

18 / 20

Less repeated work

18 of 20 long Sage sessions contained duplicated context work. This runtime surfaces redundant re-reads, bounds worker execution, and keeps completion wakeups compact.

EVIDENCE

Verify the effect, not the status

A successful tool response does not prove the intended outcome exists. The operating principle is to check the real output, public interface, or changed file.

REVERSIBLE

Changes need a way back

Updates are versioned, recipient config is preserved, and rollback is included. Parallel work has budgets instead of unlimited fan-out.

Why Memory matters to a normal person

Project memory without the busywork

Memory embeddings turn your notes, decisions, and context into numbers the agent can search quickly. You do not write search queries — the agent remembers what is relevant. Memory sidecar is a small helper that watches for important facts as you work.

In plain words: the agent remembers what you decided last week without manually copying it into notes.

Honest note on embeddings: local embeddings may perform a transparent one-time model download on first memory use. This is standard for local memory — nothing extra to configure. After that, memory runs locally and offline.

Developer workflow

Lite includes our full dev-workflow that we use every day. It does not require knowing Rust or Git — but if you do, the agent connects at that level.

01 · TDD

Tests first

The agent writes a test that describes the expected behavior. Then the code that makes the test pass. This removes a lot of "almost works."

02 · VERIFY

Check, don't trust

Every change has a concrete way to verify: build, test, real output. The agent does not say "done" until you see the result.

03 · REVERT

There is always a way back

Every action lands in git track. Complex changes are blocked without a way to roll back. This fixes many errors before they happen.

04 · DECIDE

Clear decision points

The agent stops and asks for your input between options. It does not "decide for you" — it asks for a short choice.

05 · DELEGATE

Divides complex work

Swarm mechanics split a large task between workers with bounded runtime budgets and compact reports. The main agent does not drown in details.

06 · COMMIT

Frequent small commits

The agent commits often in small, readable chunks. Easier to see what changed, faster to roll back if needed.

Honest trade-offs

Lite delivers more out of the box, but the install is heavier than Lite Free. That is not an advantage for everyone.

Choose Lite when

  • You want Stables bundled with no provider setup.
  • You want 19 business roles and 6 workflow wrappers ready.
  • Memory with embeddings and sidecar should work immediately.
  • Mage, Knowledge OS, headless Playwright, and PDF out of the box.

Choose Lite Free or Original when

  • You want your own provider — pick Lite Free.
  • You need Linux or full-feature build — pick Original Jcode.
  • You do not want the extra install size — Lite Free is noticeably lighter.

Honest cons

These are things to know before installing. We do not hide that Lite is more than Lite Free.

  • Larger install size. Lite bundles Stables routing, 19 skills, memory embeddings, Mage, Knowledge OS, PDF, and Playwright. The downloaded archive is noticeably bigger than Lite Free.
  • Node.js 20 or newer required for Mage and Knowledge OS.
  • A system browser is required. Headless Playwright uses your installed Chrome or Edge in isolated headless mode. Lite does not ship its own browser — you need a stable local browser.
  • Optional MCP service keys. Reddit bundled is anonymous-first — works without setup for subreddit browsing via public RSS. Free Reddit credentials are an optional unlock for search, comments, user analysis, and higher limits. Notion, OmniSearch, Lerim memory need their own API keys for full functionality.
  • Stables bundled means higher opacity threshold. If you do not want anyone else paying for your AI — pick Lite Free.
